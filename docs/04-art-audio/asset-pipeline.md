# Asset Pipeline

## Folder layout

```
assets/
├── MANIFEST.csv            every shipped asset: path, type, source, author, license, url, notes
├── voxel/
│   ├── src/*.vox           MagicaVoxel sources (authored or procedurally generated)
│   └── procedural/*.ts     code that GENERATES .vox (crops by stage, fences, rocks)
├── audio/
│   ├── sfx/src/*.wav       sources (or .sfxr.json presets for generated sfx)
│   └── music/src/*.wav     stems per track
├── textures/               skybox gradients, UI grain (small)
└── fonts/                  OFL fonts + license files
```

Build outputs go to `apps/web/public/assets/` (git-ignored, produced in CI).

## Voxel pipeline

```
.vox (MagicaVoxel)  ─┐
procedural/*.ts ─► .vox ─┴─► tools/voxel-bake ─► .glb (greedy mesh, vertex colors, baked AO)
                                              └─► .png icon (orthographic render, 64/128 px)
```

- `tools/voxel-bake` uses a `.vox` parser plus greedy meshing, writes glTF with `@gltf-transform/core`, then runs meshopt compression.
- **Per-vertex AO** is baked at build time (the standard voxel AO corner technique), which removes the need for heavy runtime AO on low-end devices.
- **Color noise:** a deterministic per-voxel ±3 % value jitter is applied at bake time so authors can paint flat colors.
- **Procedural generation:** crop growth stages, fences, rocks and terrain backdrops can be *generated by code* with seeded parameters (stalk height, leaf count, curvature). This is how we "generate art" reliably: it's consistent, editable, license-clean, and an artist (or Claude) can iterate by tweaking parameters. Hero assets (drones, farmhouse, avatars) are hand-authored or commissioned.
- **Runtime fallback for dev:** three.js ships a `VOXLoader`, so raw `.vox` can be previewed without baking.

## Audio pipeline

```
sfx: .wav or .sfxr.json ─► tools/audio-build ─► normalised (−16 LUFS sfx / −18 LUFS music)
                                              ─► .ogg (Opus) + .m4a (AAC fallback for Safari)
                                              ─► sprite sheet (sfx) + manifest JSON
music: stems (.wav) ─► loudness-match ─► .ogg/.m4a per stem, seamless loop points in manifest
```

## License gate (CI)

`tools/asset-check` fails the build if:
- a file under `assets/` (excluding `src` working files explicitly marked `wip`) has no row in `MANIFEST.csv`
- a license is not in the allowlist: `CC0-1.0`, `CC-BY-4.0` (attribution auto-collected into the in-game Credits screen), `OFL-1.1`, `own-work`, `commissioned-exclusive`, `licensed-commercial` (with contract ref)
- a license is `NC`, `ND`, `CC-BY-SA` (share-alike is too ambiguous for game bundles, so excluded by default), or unknown

The in-game **Credits** screen is generated from `MANIFEST.csv`.
